MARTINEX — PWA MVP

This is a front-end prototype only. It does not hold or transfer real money.

FREE PUBLISHING:
1. Create a free GitHub account.
2. Create a new public repository named martinex.
3. Upload index.html, manifest.webmanifest and sw.js.
4. In Settings > Pages, choose Deploy from branch, main, /root.
5. GitHub will provide a public https://...github.io/... address.
6. Open the address in Safari on iPhone, tap Share > Add to Home Screen.

For a real financial service, backend, KYC, security, regulated partners and legal authorization are required before real-money transactions.
